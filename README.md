# Life Mod

Мод для Minecraft 26.1.2 (Fabric) по мотивам Diversity 1.7.2: фракции, репутация,
квесты, наёмники, таверны и мушкеты. Контент (копья, духовая трубка, мумия,
скелет-воин, цицимиме, культист, текстуры племён) портирован из приложенного
DiversityMod 1.7.2; архитектура сверена с Fabric API 0.151.0+26.1.2
(наработки Better-on-Java использованы как образец структуры).

## Механики

### Фракции (13)
| Фракция | Мировоззрение | Биомы |
|---|---|---|
| Жители | добро | все биомы (классические ванильные жители) |
| Египтяне | добро | пустыни |
| Эльфы | нейтрал | джунгли (модель игрока, свои скины) |
| Северяне | добро | снежные |
| Ацтеки | зло | джунгли |
| Норды | нейтрал | снежные |
| Вегиры | нейтрал | тайга + снег (модель игрока, 19 скинов) |
| Разбойники | зло | везде (скин по биому) |
| Одичалые | зло | везде (скин по биому) |
| Наёмники | нейтрал | везде (скин по биому) |
| Пираты | зло | пляжи/океан |
| Гномы | нейтрал | подземелья |
| Гоблины | зло | подземелья |

- **Добрые** фракции не применяют насилие даже в защиту — их поселения
  охраняют железные големы, которые атакуют членов злых фракций.
- **Злые** — в состоянии войны со всеми остальными, но игрока не атакуют
  (только дают сдачи).
- **Нейтральные** могут объявлять войну (`/lifemod war declare <a> <b>`),
  могут порабощать: жертва, добитая разбойником или нейтралом, выживает
  и обращается в раба (освобождается золотым слитком).
- **Дипломатия живёт сама**: примерно каждые полчаса нейтральные фракции
  объявляют войны и заключают мир — всем игрокам приходит оповещение,
  `/lifemod war list` показывает текущие войны.

### Репутация и квесты
- ПКМ по **лидеру поселения** — взять/сдать квест. Добрые дают квесты на
  собирательство, злые (в т.ч. атаман разбойников) — только на убийства,
  иногда заказывая истребление целой вражеской фракции. Нейтральные в мирное
  время просят собирать ресурсы, а в войну — бить членов вражеской фракции.
- Награда: изумруды + репутация. `/lifemod rep` — посмотреть свою репутацию.
- Репутация ≥ 20 — можно нанимать наёмников; ≥ 50 — купить дом
  (шифт-ПКМ по лидеру с изумрудами → купчая; купчая на дверь → дом ваш навсегда).

### Наёмники
ПКМ с изумрудами (8 шт.) по наёмнику в деревнях нейтральных/злых фракций —
он следует за вами и защищает вас. Шифт-ПКМ — распустить.
Наёмники в тавернах стоят втрое дороже (24).

### Таверны
ПКМ с изумрудами по трактирщику (5 шт.) — аренда ближайшей свободной комнаты
на три игровых дня: дверь отпирается только для вас.

### Структуры
В мире генерируются (data-driven jigsaw, NBT-шаблоны):
- **Деревни фракций** (32×32: дом лидера, три дома, колодец, ферма, фонари) —
  египтяне (пустыни), северяне и норды (снега), ацтеки и эльфы (джунгли),
  вегиры (тайга/снега), разбойники, одичалые и наёмники (везде),
  **пираты на пляжах** — с причалом, сундуком добычи, мушкетёрами и рабыней.
- **Лагеря фракций** — уменьшенный вариант (хижина с лидером, шатёр, костёр),
  встречаются чаще деревень.
- **Таверна** (равнины/леса/тайга) — три комнаты с дверями и кроватями,
  трактирщик за стойкой и два дорогих наёмника в зале.
- **Пиратский маяк** (пляжи) — башня с огнём на вершине, пираты и мушкетёры.
- **Пиратский корабль** (океаны) — дрейфует по поверхности: капитан, команда,
  мушкетёр, трюм с сундуками добычи и пленённой рабыней.
- **Гномий колодец** (горы/холмы) — вход во владения гномов; под землёй
  отдельно генерируется **гномий зал** с троном, кузней, сокровищницей
  и лестницей-шахтой к поверхности.
- **Шахта разбойников** (под землёй) — штольни с рельсами, рудой, надсмотрщиком
  и рабами-копателями, которых можно освободить.

### Налёты разбойников
Примерно каждые 20 минут возле случайного игрока высаживается шайка из 4–6
разбойников **во главе с атаманом** (у него можно взять квест на убийства).
Игрока они не трогают, но атакуют всех жителей окрестных поселений; добитые
жертвы обращаются в рабов (раба можно выкупить золотым слитком). Големы
добрых поселений встречают налётчиков боем.

### Добыча
Все мобы мода имеют лут-таблицы: олень — кожа и **оленина** (сырая жарится в
печи/коптильне/на костре; порт еды из Better-on-Java), йети — снежки и шкуры,
тёмный паук — нить и паучий глаз, мумия/скелеты/культисты — кости, изумруды
и золото, разбойники и пираты — изумруды; с мушкетёра гарантированно падает
мушкет с боеприпасами.

### Мушкеты
Некоторые пираты — мушкетёры. Убейте мушкетёра — мушкет выпадет.
Для выстрела в инвентаре нужны **пуля** (крафт из булыжника) и
**мешочек с порохом** (4 шт. из пороха + бумаги).

### Мобы
Враждебные: йети (горы), тёмный паук, мумия (пустыни), скелет-воин,
цицимиме и культист (джунгли), гоблины (пещеры). Мирные: олень.
Пираты и фракционные жители редко спавнятся в своих биомах,
а основное население живёт в лагерях фракций (см. «Структуры»).

## Предметы
Копья 5 ярусов (метаются ПКМ), духовая трубка + отравленные дротики,
топор мира, мушкет/пуля/мешочек с порохом, купчая на дом.

## Сборка

```shell
./gradlew build
```
Jar появится в `build/libs/`. Требуется Java 25 и доступ к maven.fabricmc.net.

> **Важно:** код написан без локальной компиляции (в среде разработки не было
> доступа к maven Fabric/Mojang). Все API сверены с исходниками Fabric API
> 0.151.0+26.1.2; места, где имя маппинга не удалось подтвердить, помечены
> комментарием `// VERIFY-MAPPING` — при ошибке компиляции начните с них.

## Планы (следующие итерации)
- Многосекционные jigsaw-деревни со случайной планировкой (сейчас деревни —
  цельные шаблоны); прямой проход из гномьего колодца в подземный зал.
- Собственные модели йети/тёмного паука и текстуры пиратов/гномов
  (сейчас — заглушки и перекраски текстур Diversity). У оленя уже своя модель
  (рога, уши, хвост) с текстурой, сгенерированной под её UV-развёртку.
- Спавн-яйца, торговый GUI вместо чата.

> NBT-шаблоны структур сгенерированы скриптом с DataVersion 4189 (1.21.4) —
> игра обновит их при загрузке. Если формат worldgen-JSON в 26.1.2 изменился,
> ошибки будут видны в логе при создании мира как `Error loading structure`.
